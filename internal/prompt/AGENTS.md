# prompt

Typed, SDK-independent Jinja rendering core for SPEC-0014 §3; use `New(Options)` and `Engine.Render` with fixed request data.
- Supply a `TemplateLoader`; loader names are passed through unchanged. `NewFileSystemLoader` is the confined implementation: the `builtin/` namespace cannot be shadowed, a trusted project root overrides the user root, and `..`, absolute paths, backslashes, NUL, escaping symlinks, directories and other non-regular files are rejected. Callers pass roots and trust per load and own `Close`.
- Render with strict undefined values, whitespace controls, a 64 KiB default output limit, 16-level include depth and a 100 ms deadline.
- A deadline discards the result. It cannot preempt a single expression or a blocked loader; loops and output writes observe cancellation at their next iteration or write. `Render` cancels and joins every `range` producer before returning (`state.go`), so no producer goroutine outlives a render. A post-render deadline check is not preemption.
- `loop.go` wraps gonja's `for` parser with a local control structure (donor: gonja v2.9.1 `builtins/control_structures/for.go`, MIT, see `LICENSE.gonja`); `range.go` overrides `range` (donor `builtins/global_functions.go`). A loop-filter evaluation error fails the render, iterations poll the render context, and channel iterables are consumed lazily. Preserve loop/else/break/continue/recursive semantics when changing them; `TestFilteredLoopOutput`, `TestLoopCancellation`, `TestRenderJoinsRangeProducers` and `TestRangeProducerTerminatesOnOverflow` pin them.
- Don't iterate a channel with `exec.Value.Iterate`; it drains and preallocates the whole series before any deadline check.
- Override gonja's `attr` filter to error on missing map keys and struct attributes. Workbench owns its templates; present struct values and non-map/struct behavior are preserved, while present map keys resolve to their values.
- One template file is bounded to 256 KiB by default (`MaxFileBytes`); `List` returns reachable names sorted and confined. `helpers.go` adds the `has_tool` (declared tools) and `variant` (`family/<family>/<name>` else `<name>`) globals; tests `family`, `glob` and `regex` live in `tests.go`. Section tags and structure checks and the builtin template belong to separate components.
