# modelknowledge

Knowledge cutoffs for the `session.model` frame; no SDK, no network at run time.
- `cutoffs_gen.go` is generated by `scripts/gen_model_cutoffs.py` from models.dev; never edit it by hand, regenerate and commit the new snapshot date.
- A user entry in `models.knowledge-cutoffs` wins over the snapshot. An unknown model reports no cutoff, or one estimated from its release date and labelled as estimated; never invent an exact date.
