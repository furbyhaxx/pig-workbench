# secrets

SPEC-0013 §3 defines deterministic placeholders and key handling; this package is independent of the SDK.
- `key.go` owns key-file creation and loading; never replace an existing key or silently relax its permissions.
- Derive 32-byte HMAC keys with HKDF-SHA256, no salt, info `nukii red-sec hmac v1`; placeholders use HMAC-SHA256 and the first 16 lowercase unpadded RFC 4648 base32 characters.
- Never include key or secret bytes in errors; withhold output on any redaction error. Preserve existing placeholders during replacement.
- `vault.go` and `vault_io.go` own private append-only AES-256-GCM storage, typed errors and project-before-global environment selection. The first ciphertext for a placeholder wins; metadata and deletion use the last record.
- `Load` and mutations reread under the sidecar lock; `Value` and `Values` call `Load`. Check `Warnings()` after `Load()` for an incomplete final line; writes fail until that line is repaired. `Values()` can return partial values with `ErrDecrypt`; redaction boundaries must withhold output on any error.
- `detection.go` owns builtin token shapes, user patterns (`regex`, `prefix`, `suffix`, prefix `min-length` ≥ 8), URL passwords, exclusions and the `Detector` that binds them to a vault. `Learn` persists a value before its placeholder is used; `Redact` snapshots the vault per call (so values learned by other sessions are covered), persists newly detected values with source `detected`, and replaces longest-first while leaving canonical placeholders alone; `Substitute` resolves canonical placeholders only and fails on unknown, deleted or non-canonical records instead of leaving a marker. Any key, vault, decryption or mapping error withholds output.
- The 8-character minimum and whole-placeholder immunity filter learning and autodetection only: every nonempty stored value is redacted and substituted, because an explicitly registered short value must not leak. Excluded values (literal or `red-sec-` hash) are never learned or replaced. Env/auth inventories, policy-file loading and the LLM boundary hooks are host adapters and stay outside this package.
